# GlyphFlow

**GlyphFlow** — браузерный редактор рукописных шрифтов. Рисуйте символы каллиграфической кистью, проверяйте результат в текстовом предпросмотре и собирайте собственный файл шрифта TrueType (.ttf).

> Текущий статус: ранний MVP. Приложение уже умеет рисовать отдельные глифы и собирать TTF, но ещё не является полноценным профессиональным редактором шрифтов.

## Что работает сейчас

- Каллиграфическая кисть на базе [perfect-freehand](https://github.com/steveruizok/perfect-freehand).
- Настройка размера кисти и заострения концов.
- Рабочее поле SVG с типографскими направляющими.
- Набор символов: кириллица, латиница, цифры и часть пунктуации.
- Переключение между глифами.
- Отмена и повтор действий в рамках текущей сессии.
- Локальное сохранение черновика в IndexedDB и попытка восстановления при повторном открытии.
- Текстовый предпросмотр и экспорт TTF через [opentype.js](https://github.com/opentypejs/opentype.js).

## Запуск

Откройте `index.html` через локальный HTTP-сервер. Например, при установленном Python:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`. Для загрузки модулей из CDN при первом запуске требуется подключение к интернету.

## Как пользоваться

1. Выберите символ в левой панели.
2. Нарисуйте его на белом поле.
3. Настройте толщину и заострение кисти.
4. Перейдите к другим символам и нарисуйте нужный набор.
5. Введите текст в поле предпросмотра.
6. Задайте название семейства и нажмите «Скачать .TTF».

Черновик хранится локально в браузере на этом устройстве. Очистка данных сайта или хранилища браузера может удалить черновик. Это не облачная синхронизация и не резервная копия.

## Известные ограничения

- Пока доступна только каллиграфическая кисть; карандаш, перо Безье и векторный ластик ещё не реализованы.
- История действий пока простая и ограничена текущей сессией.
- Нет импорта SVG, слоёв, полноценного редактирования узлов и кернинга.
- Геометрическая проверка контуров и расширенная проверка собранного TTF ещё требуются.
- Метрики шрифта и боковые интервалы требуют отдельной типографской доработки.
- PWA, Service Worker и гарантированная офлайн-работа пока не реализованы.
- Внешние библиотеки загружаются с CDN.

## План развития

1. Укрепить ввод указателя, восстановление и тестирование на мобильных устройствах.
2. Развить модель глифов и надёжную историю изменений.
3. Добавить валидатор геометрии и комплексные проверки TTF.
4. Реализовать карандаш и перо Безье.
5. Добавить выделение, векторный ластик, слои и импорт SVG.

7. Добавить PWA, офлайн-режим и автоматические тесты.

## Технологии

- HTML, CSS и JavaScript (ES modules)
- SVG для векторного рабочего поля
- perfect-freehand для построения каллиграфических контуров
- opentype.js для создания TrueType-шрифта
- IndexedDB для локальных черновиков

## Автоматические проверки

GitHub Actions проверяет синтаксис встроенного JavaScript и ключевые контракты редактора, затем создаёт тестовый TTF через opentype.js 1.3.4 и проверяет его двумя парсерами: opentype.js и независимым Python FontTools. Проверяются базовые метрики, `.notdef`, пробел, Unicode, количество контуров и направление обхода.

Эти проверки полезны для контроля сборки, но не заменяют ручную проверку рисунка букв, браузеров и сторонних шрифтовых редакторов.
