# GlyphFlow# ✍️ GlyphFlow — Генератор рукописных шрифтов

Веб-приложение для создания собственных рукописных шрифтов (`.ttf`) прямо в браузере с помощью каллиграфической кисти.

![GlyphFlow Demo](https://img.shields.io/badge/status-MVP-orange)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Возможности

- **Живая каллиграфическая кисть:** плавные линии с настройкой толщины и заострения концов (на базе `perfect-freehand`)
- **Типографские направляющие:** разметка для базовой линии, прописных, строчных букв и нижних выносных элементов
- **Поддержка языков:** готовая сетка для кириллицы, латиницы, цифр и знаков препинания
- **Предпросмотр в реальном времени:** проверка нарисованных букв в тексте без перезагрузки страницы
- **Экспорт в `.TTF`:** мгновенная сборка и скачивание файла шрифта на стороне клиента (на базе `opentype.js`)
