# GlyphFlow — checklist пакета публикации шрифта

Документ описывает требования к экспортному комплекту. Наличие этого файла не означает, что конкретный шрифт уже готов к публикации.

## Состав архива одного семейства
- [ ] Файлы шрифта TTF для всех заявленных стилей.
- [ ] OFL.txt — только после подтверждения автором выбора SIL Open Font License 1.1 и проверки прав на все включённые материалы.
- [ ] OFL-FAQ.txt — актуальная официальная версия FAQ, если требуется каналом распространения.
- [ ] FONTLOG.txt — история версий, изменений контуров и метрик.
- [ ] README.md — автор, название семейства, версия, описание, поддержка Unicode, установка и известные ограничения.
- [ ] glyph-catalog.json — паспорт всех включённых глифов.
- [ ] glyph-coverage.txt — фактическая таблица Unicode cmap и перечень отсутствующих/неподдерживаемых символов.
- [ ] specimen.pdf — образцы алфавитов, цифр, пунктуации, языковых примеров и размеров.
- [ ] source/ — исходные редактируемые данные проекта, если они предназначены для распространения.
- [ ] SHA-256 контрольные суммы файлов архива.

## Метаданные семейства
- Family Name и уникальное PostScript Name.
- Version string и номер версии.
- Designer / автор: Lina1209.
- Авторская подпись / студия: Lina1209 Mirror Studio (если автор подтверждает это обозначение для конкретного семейства).
- Copyright notice и год.
- License URL и лицензия.
- Языковая и Unicode coverage.
- Названия и описания каждого глифа.

## Проверки перед выпуском
1. Проверить cmap: каждый заявленный Unicode code point должен вести к ожидаемому глифу.
2. Проверить имена глифов, уникальность PostScript-имён и отсутствие дубликатов.
3. Проверить контуры, направление обхода, экстремумы, нулевые/самопересекающиеся контуры и композитные глифы.
4. Проверить метрики: units per em, advance width, side bearings, ascender/descender, line gap.
5. Проверить таблицы name, OS/2, head, hhea, maxp, cmap, glyf, loca и post.
6. Прогнать FontTools и независимые проверки качества; для Google Fonts — актуальный FontBakery/Fontspector и требования репозитория Google Fonts.
7. Установить и проверить шрифт в нескольких ОС и приложениях; проверить кириллицу, латиницу, цифры, пунктуацию и переносы.
8. Сверить архив и документацию, сформировать SHA-256.

## Лицензионное решение — требуется подтверждение
Для подачи в Google Fonts обычно выбирают SIL Open Font License 1.1. Это юридически значимое разрешение на использование, модификацию и распространение шрифта; нельзя автоматически назначать его без подтверждения правообладателя. До подтверждения не создавать файл лицензии с подписью автора и не маркировать шрифт как OFL.

Также необходимо убедиться, что все контуры, исходники и включённые сторонние компоненты имеют совместимые права. Условия лицензии приложения GlyphFlow и лицензия создаваемого шрифта — разные вопросы.

## Текущий статус
Пока это план упаковки. Наличие TTF-экспорта, локального паспорта и импортёра UCD не означает, что собран архив публикации или пройдены проверки Google Fonts.
